# Prototipe SUMBAWA TRIP — V5 Photo Integrated

## Route prototipe

Setelah build, buka `/sumbawa-trip/` pada local preview atau URL GitHub Pages yang sesuai.

## Desain yang dipertahankan

- Identitas SUMBAWA TRIP dan tagline "YOUR GATEWAY TO SUMBAWA ADVENTURE".
- Arah visual V5: hijau hutan, hijau gelap, gold, dan cream; hero besar; experience cards; journey cards; about; gallery; CTA.
- Mobile navigation dengan menu hamburger.
- Detail journey yang bisa dibuka/tutup, itinerary per hari, dan bagian What's included / What's not included yang collapsible.
- CTA konsultasi WhatsApp dengan pesan awal per paket.

## Penting sebelum publikasi

- Gambar eksternal saat ini hanya referensi visual sementara dari galeri publik Sumbawa Holiday Tour. Ganti seluruhnya dengan foto asli yang dimiliki SUMBAWA TRIP atau telah mendapat izin sebelum website dipublikasikan.
- Nomor WhatsApp 0812-4620-3185 merupakan kontak sementara yang pernah tercantum pada brief project; verifikasi kembali.
- Harga Moyo Rp 2.925.000/pax (2 pax) berasal dari materi lama dan harus dikonfirmasi ulang.
- Harga, durasi, rute, akomodasi, layanan, dan itinerary untuk setiap paket perlu disetujui sebelum dipakai sebagai penawaran.
- Data lama memiliki konflik durasi untuk beberapa paket (khususnya offroad Tambora dan pendakian via Pancasila). Prototipe menandai bagian ini sebagai perlu konfirmasi dan tidak menganggap detail tersebut final.
- Form booking belum menyimpan data dan pembayaran otomatis belum tersedia. CTA saat ini hanya membuka WhatsApp.
- Foto dan copy placeholder tidak boleh dianggap sebagai versi siap produksi.
